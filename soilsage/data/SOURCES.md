# Data Sources (download manually into data/raw/)

Target: 30-50 PDFs. Name files clearly, e.g. `fao_soil_guide_2017.pdf`.

| Source | Where | What to grab |
|--------|-------|--------------|
| Soil Health Card portal | soilhealth.dac.gov.in | Crop-wise fertilizer recommendation docs, SHC guidelines |
| ICAR | icar.org.in | Soil fertility manuals, crop production guides |
| NBSS&LUP | nbsslup.icar.gov.in | Soil survey reports, soil maps documentation |
| FAO | fao.org/soils-portal | Soil management guides, fertilizer guides |
| State agri universities | PAU, TNAU, IARI sites | Package of practices (crop-wise) |
| Kaggle | "Crop Recommendation Dataset" | Put CSV in data/crop_recommendation.csv |

Tip: prefer text-based PDFs. Scanned PDFs need OCR (add later).
